# Focus Timer

A Pomodoro focus timer web app with a large circular countdown.

## Features

- Large circular countdown ring
- Focus / short break / long break modes — long break after every 4 focus rounds
- Task name shown inside the ring
- Presets: 15 / 25 / 50 / 90 minutes, plus fine +/- 1 minute adjustment
- Auto-start break option
- End-of-session sound toggle
- Session stats for the current visit (completed focus sessions, total focus minutes, breaks taken)
- Keyboard shortcuts: `Space` start/pause, `R` reset

## Usage

Open `index.html` in any browser, or serve it with any static host. No build step, no dependencies.
